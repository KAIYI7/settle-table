# Prepublication rights and asset review

Reviewed 2026-10-17. **Conditional recommendation: publish a source/documentation baseline with local runtime, downloaded datasets/models and uncleared vendored payloads excluded.** This review does not publish anything, select a project license or authorize asset redistribution. The orchestrator owns staging, sanitization, Git operations and remote verification.

Dependency trees under the OCR environment were deliberately pruned from recursive content inspection rather than treated as reviewed source.
- [Existing reuse assessment](../licensing-and-reuse.md) records reference-only treatment for ReceiptIQ, Notion Expense Automation and the ambiguously licensed Ai-bill-splitter. Repository reports are independent analysis, not grants to redistribute those applications.
- The installed Matt collection is pinned to `49dd158d1076134a641b33efb035946536778336`; its retained `MATTPOCOCK-LICENSE.txt` includes the MIT grant and copyright notice. [Official pinned license](https://github.com/mattpocock/skills/blob/49dd158d1076134a641b33efb035946536778336/LICENSE) was rechecked.
- Impeccable source is pinned to `5bf0a069dc857e1b5f4b090e004d9d5b231416ca`; retained `IMPECCABLE-LICENSE.txt` is Apache-2.0 and includes Paul Bakaus attribution. [Official pinned license](https://raw.githubusercontent.com/pbakaus/impeccable/5bf0a069dc857e1b5f4b090e004d9d5b231416ca/LICENSE) was rechecked. Apache redistribution requires the license, applicable notices and notices on modified files; it is not evidence that every bundled dependency has been audited.

The [official current grant](https://raw.githubusercontent.com/ehmo/platform-design-skills/main/LICENSE), accessed on this review date, is MIT with a 2026 copyright line; its exact historical source revision is not identified by the installed notice.

The executable is the recorded official `engine-v0.1.15` artifact with installation SHA256 `981324ea15cc3c107d46b8133b5be77f639dbcd22e671f1eb7d8c69136e9693b`; [official release](https://github.com/pbakaus/impeccable/releases/tag/engine-v0.1.15). A valid checksum establishes artifact identity, not transitive redistribution clearance. No fonts were found as font binaries outside ignored dependencies; the catalog itself is metadata.

Curator CC-BY-4.0 provenance remains qualified because original competition rights were not independently recovered; see [OCR evidence](../phase-1/ocr-validation.md). Do not present the receipt fixtures as cleared product assets.
- Three disposable SQLite files were found outside OCR dependency trees: the Notion simulation and two Phase 2 transaction runs. They are reproducible runtime state, not necessary source fixtures.

## Orchestrator preflight conditions

1. Select a concrete vendor policy. Safe minimal route: retain Matt MIT skills if useful, exclude the entire Impeccable payload, keep its provenance/licenses/setup instructions and preserve local installed files. Excluding **all** installed vendor payloads is also viable if restore instructions retain exact upstream revisions and published collection enumeration.
2. Confirm staging includes neither downloaded media/models nor raw receipt transcriptions, local databases, upstream application snapshots or the Windows executable. Keep source/scripts and sanitized aggregate evidence instead.
3. Keep missing-artifact documentation honest: when raw evidence remains local for rights/privacy, say so; do not claim a public clone contains the original ten-image benchmark or can run every experiment without separately provisioning inputs.
4. Do not label the entire project MIT/Apache merely because its skills have those grants. No project-wide license was selected by earlier research. Publishing this authorized baseline need not invent a new grant: [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) distinguishes repository visibility from choosing an open-source license.

## Limits

This is a bounded source/asset rights inventory, not a transitive SBOM, legal clearance, secret scan or review of implementation behavior. Dependency/model caches were not exhaustively enumerated because the recommendation excludes them. Web retrieval of the pinned Impeccable NOTICE path failed; the retained local notice and prior installation manifest supply that observation, while its pinned LICENSE and the current named third-party MIT grant were retrievable. No private URLs, credentials or account identifiers are recorded here. No local installation, source file, ignore rule or external resource was changed by this reviewer; only this report was created.

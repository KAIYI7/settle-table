# Disposable Phase 1 experiments

These files answer technical/domain questions only. They are not production modules, application scaffolding, or a final schema. They may be discarded or rewritten after review.

- `domain/`: integer-money conservation and workflow scenarios; deterministic results.
- `ocr/`: corpus manifests, engine/parsing comparisons, rights/source records and measured outputs.
- `notion/`: synthetic schema/synchronization probes; real scratch resources, if any, explicitly named and recorded.

Do not add real credentials or private receipt images to versioned results. Pin input hashes, engine/dependency versions, hardware/timing methodology and evidence limitations. Monetary values are integer minor units (MYR sen); quantities can be exact rationals and latency/confidence may use nonmonetary decimals. Unknown fields are unknown, never silently zero.

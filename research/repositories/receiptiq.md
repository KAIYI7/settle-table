## Contradictions and reuse decisions

- README describes an optional free refinement layer; source confirms optionality and failure fallback, but it refines all receipts when enabled, rather than escalating only weak results. Preserve that distinction in architecture recommendations.
- README calls local OCR deterministic/free forever and claims superiority to Tesseract. These are author assertions, not a reproducible cross-engine Malaysian benchmark. Model/runtime versions and inference hardware affect results.
- Useful patterns to independently implement: OCR box-to-line grouping; pure parser isolated from OCR; store raw text/engine/warnings; schema-validated optional fallback; local fixture-based tests; same-origin API/UI.
- Do not reuse code without license grant. Avoid floats for money, English-centric heuristics, dropping low-confidence evidence, unconditional configured LLM calls, automatic model overwrites, public unauthenticated receipt API, wildcard CORS, orphaned image retention and inability to correct stored records.

## Unresolved / limits

No dependencies or OCR models installed for this review; no test pass/latency/accuracy claim independently verified. Default RapidOCR package/model redistribution terms, PyMuPDF obligations, OpenRouter model availability, concurrency safety and image retention are adoption blockers/questions. A local-first design is supported as a candidate by its structure, not validated for our target dataset.
